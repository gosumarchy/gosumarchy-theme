# Rainy themes for Omarchy (moved)

The themes now live in one repo each, so they install with `omarchy theme install`:

- [omarchy-rainy-harbor-theme](https://github.com/gosumarchy/omarchy-rainy-harbor-theme)
- [omarchy-rainy-window-theme](https://github.com/gosumarchy/omarchy-rainy-window-theme)
- [omarchy-rainy-storm-theme](https://github.com/gosumarchy/omarchy-rainy-storm-theme)

```sh
omarchy theme install https://github.com/gosumarchy/omarchy-rainy-harbor-theme
```

This repo is archived. Its `hyprland.lua` settings moved into the window-look snippet in
each theme's README, because Omarchy drops Lua from installed themes.
